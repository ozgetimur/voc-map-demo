# VOC Map Demo

A small practice web app: a **searchable world map of VOC measurement sites** with **filtered CSV download**.
It is built with Python (Flask), SQLite and Leaflet.

> ⚠️ The data in `data/` is **synthetic**. It is generated by `scripts/make_demo_data.py` for practice and is not real measurement data.

![tests](https://github.com/ozgetimur/voc-map-demo/actions/workflows/ci.yml/badge.svg)

**Live demo:** <https://voc-map-demo.onrender.com>

## Features
- Interactive map (Leaflet + OpenStreetMap), with markers colored by site type
- Filters for compound and site type
- Download the currently filtered data as CSV
- JSON API that returns GeoJSON (`/api/sites`)
- Health check endpoint (`/health`)

## Project structure
```
app.py                 Flask app (routes, input validation, CSV export)
db.py                  SQLite schema, CSV → database import, queries
data/                  sites.csv + measurements.csv (synthetic)
templates/index.html   page layout
static/map.js          map + filters (fetches /api/sites)
tests/test_app.py      pytest tests
scripts/               demo-data generator
Dockerfile, render.yaml, .github/workflows/ci.yml   deployment + CI
```

## Run locally
```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
python app.py                      # open http://127.0.0.1:5000
```
The SQLite database is built automatically from the CSV files on first start.

## Run tests
```bash
pytest -q
```
The tests also run automatically on every push through GitHub Actions.

## Deploy
**Render (free):** push the repository to GitHub, then go to Render → *New → Blueprint* and select the repo. `render.yaml` contains the build and start commands.

**Docker:**
```bash
docker build -t voc-map-demo .
docker run -p 8000:8000 voc-map-demo     # http://localhost:8000
```

## Configuration (environment variables)
| Variable | Default | Purpose |
|---|---|---|
| `VOC_DB_PATH` | `./voc_demo.sqlite` | database file location |
| `VOC_DATA_DIR` | `./data` | folder with the CSV files |
| `LOG_LEVEL` | `INFO` | logging level |
| `FLASK_DEBUG` | off | set to `1` only for local development |

## Production-readiness choices
- **gunicorn** serves the app in production instead of Flask's development server; debug mode is off by default
- **Parameterized SQL queries** (`?`) and whitelisted filter values protect against SQL injection
- Settings come from **environment variables**; dependency versions are **pinned**
- **Database indexes** on the filtered columns
- **Logging** of downloads and a **health check** for monitoring
- The container runs as a **non-root user**
- **Automated tests** and **CI**
